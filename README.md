# 우리 반 알림장

학생들에게 **전달사항**을 올리고, **학급 일정**과 **시간표**를 공유하고,
학생이 **면담 시간을 직접 예약**할 수 있는 모바일용 한 장짜리 사이트입니다.
GitHub Pages 같은 정적 호스팅에 그대로 올려서 씁니다.

- 학생: 로그인 없이 열람 + 면담 신청
- 선생님: 로그인 후 전달사항 · 일정 · 시간표 작성/수정, 예약자 이름과 면담 내용 확인

## 1단계 — 그냥 열어 보기

`index.html`을 브라우저로 열면 바로 동작합니다. 이 상태는 **데모 모드**로,
모든 내용이 그 브라우저에만 저장되고 다른 사람에게는 보이지 않습니다.
화면 오른쪽 위 **선생님 로그인**을 누르면 비밀번호 없이 선생님 화면을 둘러볼 수 있습니다.

기능만 먼저 확인하고 싶다면 여기서 멈춰도 됩니다.

## 2단계 — Firebase 연결 (학생들과 함께 쓰려면 필수)

정적 사이트라 서버가 없기 때문에, 여러 사람이 같은 자료를 보려면 데이터베이스가 필요합니다.
Firebase 무료 요금제(Spark)로 충분합니다. 결제 수단 등록도 필요 없습니다.

1. <https://console.firebase.google.com> 에서 **프로젝트 만들기** (Google Analytics는 꺼도 됩니다)
2. 왼쪽 **빌드 → Firestore Database → 데이터베이스 만들기**
   - 위치는 `asia-northeast3 (서울)` 권장
   - 시작 모드는 아무거나 골라도 됩니다. 3단계에서 규칙을 덮어씁니다.
3. **빌드 → Authentication → 시작하기 → 이메일/비밀번호** 사용 설정
   - **Users** 탭 → **사용자 추가**로 선생님 계정(이메일 + 비밀번호)을 하나 만듭니다.
     이게 로그인에 쓸 계정입니다.
4. 설정값 세 개를 `index.html` 위쪽에 옮겨 적습니다.

   **왼쪽 위 톱니바퀴 → 프로젝트 설정 → 일반** 탭을 열면 두 값이 바로 있습니다.

   | 콘솔에 적힌 이름 | 넣을 곳 |
   |---|---|
   | 프로젝트 ID | `projectId` |
   | 웹 API 키 | `apiKey` |
   | (직접 만들기) `프로젝트ID.firebaseapp.com` | `authDomain` |

```js
var FIREBASE_CONFIG = {
  apiKey: "AIza...",
  authDomain: "our-class-2026.firebaseapp.com",
  projectId: "our-class-2026",
  appId: ""
};
```

> **`appId`는 비워 두세요.** 애널리틱스에 쓰는 값이라 이 사이트(로그인 + 데이터베이스)에는
> 필요 없습니다. `authDomain`도 안 적으면 프로젝트 ID로 알아서 만들어 씁니다.

## 3단계 — 접근 규칙 넣기 (건너뛰지 마세요)

**Firestore Database → 규칙** 탭에 `firestore.rules` 내용을 통째로 붙여넣고,
`TEACHER_EMAIL` 자리에 3단계에서 만든 선생님 계정 이메일을 적은 뒤 **게시**를 누릅니다.

```
&& request.auth.token.email in ['teacher@example.com'];
```

이 규칙이 하는 일:

- 전달사항 · 일정 · 시간표 → **누구나 읽기, 선생님만 쓰기**
- 면담 예약 → **누구나 신청 가능하지만, 이미 찬 자리는 서버에서 거부** (동시 신청해도 한 명만 성공)
- 신청자 **이름과 면담 내용은 선생님만 읽을 수 있음** — 학생 화면에는 "예약됨"만 뜹니다

규칙을 게시하지 않으면 아무나 전달사항을 고칠 수 있습니다.

## 4단계 — GitHub Pages 배포

```bash
git init
git add index.html firestore.rules README.md
git commit -m "우리 반 알림장"
git branch -M main
git remote add origin https://github.com/<아이디>/<저장소>.git
git push -u origin main
```

저장소 **Settings → Pages → Source: Deploy from a branch → main / (root)** 로 설정하면
1~2분 뒤 `https://<아이디>.github.io/<저장소>/` 에서 열립니다.

마지막으로 Firebase 콘솔 **Authentication → Settings → 승인된 도메인**에
`<아이디>.github.io` 를 추가해야 로그인이 됩니다.

## 알아 두실 점

**예약 취소** — 지금은 예약을 만든 그 기기에서만 취소 버튼이 보이지만, 규칙상으로는
취소 요청 자체를 막지 않습니다. 마음먹고 브라우저 콘솔을 여는 학생이라면 남의 예약을 지울 수
있습니다. 이걸 완전히 막으려면 학생도 로그인하게 하거나 별도 서버가 필요합니다.
반대로 취소를 아예 선생님만 하게 하려면 `firestore.rules`에서
`match /bookings/{id}` 의 `allow delete: if true;` 를 `allow delete: if isTeacher();` 로 바꾸세요.

**면담 내용 보호** — 이름과 사유는 `bookingDetails` 컬렉션에 따로 저장되고, 규칙에서
선생님만 읽도록 막아 두었습니다. 학생 브라우저는 이 자료를 아예 내려받지 못합니다.

**시간표** — 선생님이 등록한 학급 시간표 한 벌을 모두가 함께 봅니다.
학생마다 다른 시간표(선택과목 등)를 넣는 기능은 아직 없습니다.

**무료 한도** — Firestore 무료 한도는 하루 읽기 5만 건입니다. 한 학급 규모라면
한참 남습니다.
