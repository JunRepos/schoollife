## 개인정보를 어떻게 나눠 두었는지

이 저장소는 **공개**입니다. GitHub Pages 무료 플랜이 공개 저장소를 요구하기 때문입니다.
그래서 민감한 정도에 따라 자료를 세 곳에 나눠 두었습니다.

| 자료 | 어디에 | 누가 볼 수 있나 |
|---|---|---|
| 학번별 시간표 | `ttdata.js` (공개 저장소) | 누구나. 이름이 없어 누구 것인지는 알 수 없습니다 |
| 학생 이름 명단 | Firestore `students` | **선생님만** |
| 상담·행동특성 누가기록 | Firestore `records` | **선생님만.** 학생 본인도 못 봅니다 |
| 교과 성적 (원점수·성취도·등급) | Firestore `grades` | **선생님만.** 학생 본인도 못 봅니다 |
| 대학별 환산표 | Firestore `unis` | **선생님만** |
| 면담 신청자 학번·사유 | Firestore `bookingDetails` | **선생님만** |
| 1인 1역 배정 | Firestore `roles` | 누구나. **번호만** 담기고 이름은 없습니다 |

성적 엑셀은 **선생님 브라우저 안에서만** 열립니다. 파일 자체가 저장소나 다른 서버로
올라가지 않고, 읽어 낸 결과만 위 `grades` 에 저장됩니다.

**학생 이름은 코드에 넣지 않았습니다.** 미성년자 21명의 이름과 시간표가 함께 공개
저장소에 올라가면 검색에도 걸리기 때문입니다. 이름은 선생님이 로그인한 뒤
**학생 기록 → 명단 등록**에서 한 번 붙여 넣으면 Firestore에 저장됩니다.

**학번 로그인은 비밀번호가 아닙니다.** 학번은 서로 다 아는 값이라 누구나 남의 학번을
넣어 볼 수 있습니다. 그래서 학번으로 볼 수 있는 것은 **시간표뿐**이고, 누가기록이나
남의 면담 내용은 학번을 넣어도 절대 보이지 않습니다.

## 자료실에 파일 올리기

PDF·한글·사진을 자료실에 바로 올리려면 파일 보관함(Firebase Storage)이 필요합니다.
2026년 2월 3일부터 보관함은 **Blaze 요금제(결제수단 등록)** 를 요구합니다.
무료 한도(5GB 보관, 월 100GB 내려받기) 안에서는 청구 금액이 0원이지만, 카드는 등록해야 합니다.

1. **Blaze 로 올리기** — 콘솔 왼쪽 아래 요금제 → Blaze 선택 → 결제수단 등록.
   바로 **예산 알림**을 걸어 두세요 (결제 → 예산 및 알림 → 월 1,000원쯤에 알림).
   한 학급 자료로 무료 한도를 넘길 일은 사실상 없습니다.
2. **Storage 시작** — 빌드 → Storage → 시작하기. 위치는 `asia-northeast3 (서울)`.
3. **규칙 게시** — Storage → **Rules** 탭에 `storage.rules` 내용을 붙여넣고
   `TEACHER_EMAIL` 을 선생님 이메일로 바꾼 뒤 게시.
   (Firestore 규칙과 **다른 파일**입니다. 둘 다 게시해야 합니다.)

파일 한 개는 50MB까지입니다. 올린 파일은 학생이 자료실에서 **보기**를 누르면
브라우저에서 바로 열립니다. 자료를 지우면 파일도 같이 지워집니다.

### 규칙 갱신하는 법

Firebase 콘솔 → **Firestore Database → 규칙** 탭에 `firestore.rules` 내용을 통째로
붙여넣고, `TEACHER_EMAIL` 자리에 선생님 계정 이메일을 적은 뒤 **게시**를 누릅니다.

```
&& request.auth.token.email in ['선생님이메일@example.com'];
```

**이걸 하기 전에는 누가기록을 쓰지 마세요.** 새 컬렉션(`students`, `records`,
`resources`)에 대한 규칙이 없으면 기본값에 따라 막히거나 열립니다.

## 1인 1역

선생님으로 로그인 → **1인1역** 탭.

- **빈 자리 모두 뽑기** — 아직 역할이 없는 학생 중에서 랜덤으로 빈 자리를 채웁니다.
  이미 정해진 학생은 그대로 둡니다. 역할 카드의 **뽑기**는 그 역할만 채웁니다
- **자리 누르기** — 빈 자리는 학생을 직접 고르거나 랜덤으로 한 명 뽑고, 차 있는 자리는
  다른 학생으로 바꾸거나 뺍니다. 다른 역할을 맡은 학생을 고르면 이쪽으로 옮겨집니다
- **되돌리기** — 뽑기나 전체 비우기 직후에 한 번 되돌릴 수 있습니다
- 한 학생은 한 역할만 맡습니다. 기본 역할 9개의 자리를 모두 더하면 20자리라, 21명 중 1명은 남습니다

학생 화면에는 **번호만** 보이고, 학번을 넣은 학생은 자기 역할이 강조됩니다.
이름은 선생님 화면에서만, 명단을 등록했을 때 붙습니다.

## 성적과 환산

**성적 불러오기** — 학생 탭 → `성적 불러오기` → 나이스 교과학습발달상황 엑셀 선택.
파일의 번호(1~21)를 학번(20601~20621)으로 잇고, 명단 이름과 다르면 저장 전에 알려 줍니다.
같은 파일을 다시 넣으면 덮어씁니다. 학기가 끝날 때마다 새로 넣으면 됩니다.

**평균 등급** — 석차등급이 나오는 과목만, 학점 가중 평균입니다.
`Σ(등급 × 학점) ÷ Σ학점`. 체육·예술·교양처럼 등급이 없는 과목은 빠집니다.

**9등급 환산은 추정치입니다.** 5등급제와 9등급제 사이에 공식 대응표가 없습니다.
이 앱은 5등급 각 구간의 한가운데를 누적 상위 %로 잡고(1등급 5%, 2등급 22%, 3등급 50%,
4등급 78%, 5등급 95%) 9등급 척도의 같은 위치로 옮깁니다. 기관이 실측 데이터로 만든
표와는 **0.3등급 안팎으로 차이가 납니다**. 화면에 추정 상위 %를 같이 보여 주니
다른 계산기와 대조해 보고 쓰세요. 실제 지원 판단의 근거로는 쓰지 마세요.

**시행계획을 직접 확인한 14개 대학은 앱에 들어 있습니다.** 경기도교육청이 모은
2028학년도 대학입학전형 시행계획 원문을 읽어 옮겼고, 카드마다 ‘시행계획 원문 확인’
표시와 쪽수 출처가 붙습니다.

| 그룹 | 대학 · 전형 |
|---|---|
| 서울 | 연세대 추천형 · 서강대 논술(교과점수) · 동국대 학교장추천인재·기회균형통합 |
| 수도권 | 아주대 고교추천 · 가천대 학생부우수자 · 서울과기대 고교추천 · 서울여대 교과우수자 · 성신여대 지역균형Ⅰ · 경기대 수시 · 삼육대 · 가톨릭대 · 국민대 |
| 국립 | 충남대 · 강원대 |

대학마다 계산 방식이 달라(등급표 / 등급×성취도 표 / 등급·성취도 혼합 / 평균등급 구간표)
세부 규정 가운데 일부는 반영하지 못했습니다. 무엇을 뺐는지는 각 카드의 ‘알아둘 점’에 적어
두었습니다.

그 밖의 대학은 학생 탭 → 대학 환산 → `＋ 대학 추가`에서 시행계획의 1~5등급 점수와
반영 교과를 넣으면 21명 점수와 반 순위가 바로 계산됩니다.

## 알아 두실 점

**예약 취소** — 지금은 예약을 만든 기기에서만 취소 버튼이 보이지만, 규칙상 취소 요청
자체는 막지 않습니다. 선생님만 취소할 수 있게 하려면 `firestore.rules` 의
`match /bookings/{id}` 에서 `allow delete: if true;` 를 `allow delete: if isTeacher();` 로
바꾸세요.

**내린 전달사항** — ‘내리기’ 한 공지는 학생 화면에서 사라지지만 데이터베이스에는 남아
있어 마음먹으면 읽을 수 있습니다. 남기면 안 되는 내용은 ‘삭제’를 쓰세요.

**학급 일정은 학생도 올리고 고칩니다** — 누구나 추가·수정할 수 있고, **지우는 것만
선생님**입니다. 시험 일정이 말없이 사라지는 일을 막기 위해서입니다. 올린 사람은
학번(학번을 넣고 쓴 경우)이나 ‘학생’으로 일정에 함께 표시됩니다. 다만 로그인이 없어
학번은 스스로 적은 값이라 확인된 신원은 아닙니다. 남의 일정을 고쳐도 막지 않으니,
장난이 잦으면 아래처럼 다시 선생님만 쓰도록 되돌리세요.

```
match /events/{id} {
  allow read: if true;
  allow write: if isTeacher();
}
```

**누가기록은 학교 공식 기록이 아닙니다** — 나이스(NEIS)에 옮겨 적기 전의 메모장으로
쓰는 것을 전제로 만들었습니다. 학교 규정상 학생 자료를 외부 서비스에 두어도 되는지는
한 번 확인해 보시는 편이 좋습니다.

**무료 한도** — Firestore 무료 한도는 하루 읽기 5만 건입니다. 한 학급 규모면 충분합니다.

## 지난 입시 결과 (어디가)

대학 카드 아래의 **지난 입시 결과**는 대입정보포털 어디가의 대학별
‘전형 평가기준 및 전년도 결과공개’ 표를 그대로 옮긴 것입니다 (`ipgyeol.js`).

| 연도 | 어디서 | 비고 |
|---|---|---|
| 2025학년도 결과 | 어디가 2026학년도 자료 | 13개 대학 |
| 2024학년도 결과 | 어디가 2025학년도 자료 | 13개 대학 (동국대·서울과기대는 이 해만) |
| 2026학년도 결과 | — | 2026년 9월 현재 어디가에 표로 올라와 있지 않음 (14개 대학 모두 확인) |

- 모집단위(학과)마다 모집인원 · 경쟁률 · 충원 · 최종등록자 학생부등급 50%/70%컷 ·
  환산점수 50%/70%컷을 담았습니다. 카드에서 **모집단위별 표 보기**를 누르면 전부 나옵니다.
- **2024·2025학년도는 9등급제입니다.** 우리 반(5등급제)과 숫자를 곧바로 견줄 수 없어,
  카드의 비교 문장은 이 학생의 반영 평균을 9등급으로 옮긴 **추정치**로만 보여 줍니다.
- **환산점수는 그 해의 산출식 기준**이라 2028 환산점수와 비교하면 안 됩니다.
- 50%컷이 70%컷보다 살짝 나쁜 곳(아주대·국민대 등 일부)은 어디가에 그렇게 게시된 값입니다.
  학생부등급은 대학 환산점수 순서로 줄 세운 학생의 별도 지표라 이런 역전이 생길 수 있습니다.
- 70%컷이 빈 칸인 모집단위는 대학이 공개하지 않은 곳입니다 (소수 인원 등).
- **서강대에는 붙이지 않았습니다.** 앱에 넣은 서강대 공식은 논술 전형의 교과점수인데,
  어디가의 서강대 교과 입결은 지역균형 전형이라 서로 다른 전형이기 때문입니다.
- 가천대는 앱의 공식이 학생부우수자 전형용이라 **학생부우수자 입결만** 붙였습니다.
